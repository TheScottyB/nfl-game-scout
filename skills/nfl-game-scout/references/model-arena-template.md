# Multi-Model Arena Scorecard Template

Append this compact scorecard at the end of every **Mode A (Full Pregame
Dossier)** so the user can run the exact same matchup across multiple AI models
(e.g., Gemini, Claude Opus/Sonnet, GPT) and compare predictions cleanly after
the game.

---

## Pregame Prediction Box (Include Verbatim Structure)

```markdown

- **Model / App:** <Model Name & App, e.g., Gemini in Antigravity / Claude in Claude Desktop>

- **Matchup:** <Away Team> at <Home Team> (<Venue>)

- **Primary Win-Script Key:** <Single biggest factor that decides the game>
- **Ref Crew Factor:** <Head Ref> — <1-line expected impact>
- **30-Day Sentiment Edge:** <Team A Score> vs <Team B Score> — <Edge/Contrarian note>
```

## Post-Game Grading Rubric (Optional — 100 Points Total)

When the user comes back after the final whistle to score models side-by-side:

| Category | Max Pts | Scoring Guide |
| :--- | :---: | :--- |
| **Straight-Up Winner** | 20 | 20 pts if correct |
| **Score & Margin Accuracy** | 20 | 20 pts within 3 pts of margin & 7 of total; scale down linearly |
| **Spread & Total Leans** | 15 | 7.5 pts each for spread and O/U |
| **Win-Script & Ref Call Accuracy** | 15 | Did the predicted game script and ref flag profile match reality? |
| **Org-Chart & Sentiment Read** | 15 | Did the highlighted coaching/sentiment edge visibly show up? |
| **Crazy Surprise Call Bonus** | 15 | 15 pts if it hits; 8–12 pts if attempted / came within inches (e.g., 71-yd free kick 1 yd short!); 0 pts if nowhere close |
